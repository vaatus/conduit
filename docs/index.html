Eight Gemini 2.5 surfaces

Extensive, not decorative.

Conduit uses Gemini 2.5 across every part of the governance loop — text, vision, reasoning, search grounding, and agentic function calling. Every call traverses Veea Lobster Trap; the architectural invariant is enforced by a CI test.

1 · Text classification

gemini-2.5-flash · JSON mode

10 categories, severity, regulatory concern, specific findings — on every paste.

2 · Text sanitization

gemini-2.5-pro

Realistic placeholders, intent preserved. The employee still gets a useful answer.

3 · Multimodal vision

gemini-2.5-flash + image

Screenshot pastes — the 2026 exfil vector nobody else catches. OCR + UI classification.

4 · Image → safe text

gemini-2.5-pro

When a screenshot is blocked, Gemini drafts a paste-safe text rewrite.

5 · Thinking-mode escalation

gemini-2.5-pro · thinking

Ambiguous classifications reasoned about. Trace surfaced in the audit detail.

6 · Search-grounded threat intel

+ google_search tool

Live rotation steps, recent breaches, threat-actor TTPs — every claim cited.

7 · Agentic narrative

function calling

Gemini investigates the audit log via Conduit's own tools, then writes the CISO brief. Trace shown.

8 · Embeddings

gemini-embedding-001

Cosine k-NN over every event. "This exfil pattern appeared three times last week."
